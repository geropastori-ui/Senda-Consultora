Uso interno y para proveedores
01

La idea

Por qué el logo es como es, en dos líneas.

Dos mitades que se equilibran, y entre ellas, el camino.

La S de Senda está armada con dos piezas iguales: un medio círculo y una barra, una girada 180° respecto de la otra. Cada pieza hace de contrapeso de la otra. El escalón que queda entre las dos es la senda: el recorrido que la consultora abre entre el problema del cliente y su resultado.

La curva habla de lo humano (escuchar, vender, acompañar). La barra recta y el corte limpio hablan de lo técnico (datos, procesos, automatización). La marca necesita las dos cosas, en equilibrio.

02

Construcción

Las medidas que no se tocan. El logo se usa siempre desde los archivos oficiales; nunca se rearma a mano.

  1. aAlto del bloque. Desde el tope de la "S" de Senda hasta la base de "CONSULTORA". Es la unidad de todo el logo.
  2. bLa S mide 1,4 veces el bloque y se centra verticalmente sobre él.
  3. cSeparación entre la S y el texto: 0,85 veces el grosor de la barra del bloque.
  4. d"CONSULTORA" mide exactamente el ancho de "Senda", de punta a punta. El interletrado se calcula para lograrlo.

05

El logo sobre cada fondo

La combinación principal es la S naranja con el texto niebla sobre pizarra. Para el resto de los fondos, estas son las únicas combinaciones válidas.

06

Lo que no se hace

Los errores más comunes al aplicar un logo. Si una pieza pide alguno de estos cambios, la pieza está mal planteada, no el logo.

07

Paleta Fiordo

Cuatro colores. El pizarra manda, la niebla da aire, el verde mar ordena y el naranja se usa poco, para que cuando aparezca se note.

08

Tipografía

Una sola familia, Red Hat, en dos cortes: Display para títulos y Text para leer. Las dos son gratuitas y están en Google Fonts, así que funcionan en Google Slides, Docs y Canva sin instalar nada.

Títulos
Aa

Red Hat Display

ExtraBold 800 para títulos, Bold 700 para subtítulos. Es la misma letra del logo. Interletrado −1% en títulos grandes.

Textos
Aa

Red Hat Text

Regular 400 para leer, Medium 500 para destacar. Dibujada para textos largos y tamaños chicos.
